# Attacks Module

This module contains adversarial perturbation generation for defeating visual geolocation systems.

## Planned Components

- **Perturbation engine**: EoT-trained adversarial perturbation generation
- **Ensemble optimization**: Multi-surrogate model targeting
- **Robustness transforms**: Crop, resize, JPEG compression simulation

This module is planned for M5 (Adversarial Perturbation Engine).
