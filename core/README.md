# Core Module

This module contains the core pipeline orchestration and shared utilities for delocaliser.

## Planned Components

- **Pipeline orchestrator**: Coordinates the multi-stage processing flow
- **Image I/O**: Handles image loading, saving, and format conversion
- **Configuration**: User settings and policy preset management
- **Logging/telemetry**: Structured logging for metrics collection

## Status

This module is under development as part of M0 (Project Kickoff).
