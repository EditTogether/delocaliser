# Evaluation Module

This module contains the evaluation harness for measuring privacy efficacy and visual fidelity.

## Planned Components

- **Proxy geolocators**: PlaNet baseline, CLIP-based retrieval, PIGEON reproduction
- **Metrics**: Haversine distance, top-k within R km, distance ECDFs
- **Visual fidelity**: LPIPS, CIEDE2000 delta-E measurement
- **Robustness evaluation**: EoT transform chain (crop, resize, JPEG)
- **Benchmarks**: IMAGEO-Bench-style evaluation, GeoChain reasoning tasks

## Status

This module is planned for M1 (Baselines & Evaluation Harness).
